# CourseAI - Smart Course Recommender

AI-powered course recommendation system using TF-IDF vectorization and cosine similarity matching.

## 🚀 Quick Start

### Web App (Main Experience)
```
start index.html
```
- Opens in default browser
- Fully client-side: no server/install needed
- Features: Recommender, catalog, themes, particles, parallax

**Or** double-click `index.html`

### Python Utility
```bash
python extract.py
```
- Extracts CSS/JS from `smart.html` → separate files
- Updates `smart.html` to link external files

## 📁 Files
| File | Description |
|------|-------------|
| `index.html` | Main app (recommended) |
| `smart.html` | Backup/alternative HTML |
| `style.css` | Responsive themes (dark/neon/light) |
| `script.js` | TF-IDF recommender + UI logic |
| `particles.js` | Mouse trails, bursts, explosions |
| `extract.py` | HTML→external CSS/JS extractor |
| `start.bat` | One-click web demo |
| `README.md` | This file |

## ✨ Features
- **50+ Courses** across AI/ML, Web, Data Science, Security, etc.
- **Real AI**: TF-IDF vectors + cosine similarity scoring
- **Smooth UX**: Particles, custom cursor, parallax, themes
- **Responsive**: Desktop + mobile touch support
- **Zero Deps**: Pure HTML/CSS/JS/Python stdlib

## 🎯 Usage
1. Open `index.html`
2. Fill profile (interests/tags/difficulty)
3. Click **Get My Recommendations** → instant matches!
